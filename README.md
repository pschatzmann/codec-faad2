Arduino (and CMake) packaging of [FAAD2](https://github.com/FreewareAdvancedAudio/faad2), the
Freeware Advanced Audio Decoder: an AAC LC / HE-AAC (SBR, PS) / MAIN / LTP decoder for ADTS, ADIF or raw AAC.

## Layout

| Path | Content |
|------|---------|
| `original/faad2` | upstream git checkout (not compiled) |
| `src/` | generated by `create_library.py` – do not edit |
| `examples/decoder-info` | Arduino sketch |

## Updating from upstream

```bash
git -C original/faad2 pull
python3 create_library.py
```

The script copies `include/neaacdec.h` and `libfaad/` into `src/`, generates `src/faad.h` and
`src/libfaad/faad_config.h` (replaces the cmake `config.h` defines) and patches `common.h` to include it,
because Arduino cannot pass compiler defines. It also patches the codebook includes and the ARM assembler in `fixed.h`
so the code compiles without the upstream build system, and generates `library.properties`, `CMakeLists.txt` and `idf_component.yml`.

## Configuration

Define these before compiling (e.g. via `build_opt.h` or `-D...`) to override the defaults:

| Define | Default | Description |
|--------|---------|-------------|
| `FIXED_POINT` | defined if the processor has no FPU | Use fixed point math |
| `FAAD_NO_FIXED_POINT` | undefined | Use floating point even without FPU |
| `LC_ONLY_DECODER` | undefined | Pure AAC LC decoder (smallest build) |
| `DISABLE_SBR` | undefined | Disable SBR (HE-AAC) decoding |
| `SBR_LOW_POWER` | undefined | Low power SBR decoding without parametric stereo |
| `DRM_SUPPORT` | undefined | Digital Radio Mondiale support |
| `FAAD_NO_APPLY_DRC` | undefined | Do not apply dynamic range control |

Fixed point is selected automatically e.g. for RP2040, SAMD21, Arduino Due, ESP32-S2, ESP32-C3, ESP32-C6 and ESP32-H2.
Floating point is used e.g. for ESP32, ESP32-S3, ESP32-P4, RP2350 and UNO R4.

## Installation

For Arduino, you can download the library as zip and call include Library -> zip library. Or you can git clone this project into the Arduino libraries folder e.g. with

```
cd  ~/Documents/Arduino/libraries
git clone https://github.com/pschatzmann/codec-faad2.git
```

This project can also be built on your desktop with cmake:

```
cd codec-faad2
mkdir build
cd build
cmake ..
make
```

CMake options: `FAAD_FIXED_POINT`, `FAAD_LC_ONLY`, `FAAD_DISABLE_SBR`, `FAAD_SBR_LOW_POWER`, `FAAD_DRM`.
Use it from another project with `add_subdirectory(codec-faad2)` and link against `faad2`.
The directory can also be used as an ESP-IDF component.

## API

```cpp
#include "neaacdec.h"

NeAACDecHandle decoder = NeAACDecOpen();

NeAACDecConfigurationPtr cfg = NeAACDecGetCurrentConfiguration(decoder);
cfg->outputFormat = FAAD_FMT_16BIT;
NeAACDecSetConfiguration(decoder, cfg);

// initialize from the first bytes of the stream (e.g. ADTS header)
unsigned long sample_rate;
unsigned char channels;
long consumed = NeAACDecInit(decoder, buffer, buffer_size, &sample_rate, &channels);

// decode frames
NeAACDecFrameInfo info;
int16_t *pcm = (int16_t *) NeAACDecDecode(decoder, &info, data, data_size);
if (info.error == 0) {
  // info.samples samples are available in pcm,
  // info.bytesconsumed bytes of the input were used
} else {
  Serial.println(NeAACDecGetErrorMessage(info.error));
}

NeAACDecClose(decoder);
```

See [src/neaacdec.h](src/neaacdec.h) and the upstream [libfaad.3](original/faad2/docs/libfaad.3) man page.
